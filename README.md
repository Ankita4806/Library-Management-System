# Library Management System

A desktop-based Library Management System developed using Java Swing and MySQL.

## Features
- Student and book details entry
- Input validation
- MySQL database connectivity
- Submit and save records
- View saved records

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Visual Studio Code

## Project Overview
This project was created to practice Java programming, object-oriented concepts, GUI development, and database connectivity.
